\# ClientPulse — Customer Relationship \& Support Management API



\*\*ClientPulse\*\* is a backend API designed to manage customer relationships, support tickets, and operational statistics. Built with Python and FastAPI, it provides a structured foundation for a modern customer support management platform.



\## Features



\### Customer Management

\- Create, retrieve, update, and delete customers.

\- Search and filter customer records.

\- Pagination support.

\- Customer status management.



\### Support Ticket Management

\- Create and manage support tickets.

\- Priority levels: Low, Medium, High, Urgent.

\- Ticket statuses: Open, In Progress, Resolved, Closed.

\- Assign tickets to team members.

\- Track creation, update, and resolution timestamps.

\- Validate customer references.



\### Dashboard \& Analytics

\- Total customer statistics.

\- Customer status breakdown.

\- Ticket status breakdown.

\- Ticket priority distribution.

\- Ticket resolution rate.



\### Quality \& Testing

\- Automated tests with pytest.

\- API tests using FastAPI TestClient.

\- Isolated SQLite test database.

\- Input validation with Pydantic.
